# Event discovery sources

Discovery sources help identify candidate events. They are not sufficient evidence
for publishing a vendor opportunity; dates, application details, fees, and vendor
eligibility still need verification from an organizer or another primary source.

## General calendars

- [Funcheap San Francisco weekend listings](https://sf.funcheap.com/weekend/) —
  useful for finding free and low-cost weekend events around San Francisco and the
  wider Bay Area.
